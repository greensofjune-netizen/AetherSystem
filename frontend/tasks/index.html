Mobile web preview. This is not a Google Play release.

Install and connection help

On Android, open your approved HTTPS app address in Chrome, sign in, then use the browser menu to Install app or Add to Home screen, if offered. A localhost preview works only on this computer, not on your phone.

A connection to your private backend is required. There is no offline task cache or background save queue. Unsaved drafts remain only in the open page and are lost on reload or closing the app. A failed save may have reached the server; check the list before trying again.

Project tasks

Tasks are stored by this Aether API. The list refreshes every five seconds. Failed saves and status updates are never retried automatically.

    Edit task

    Editing a snapshot of the displayed task. Refreshes update the list, not this draft. Save or cancel before editing another task. Only changed fields are saved. If those fields changed elsewhere, the save is rejected without writing. After an uncertain save, compare the refreshed list before retrying. Cancel editing discards this edit draft; reload discards all unsaved drafts.
