Built for local workflows

A practical API surface

Use the REST API with the same task and maintenance logic available from the Aether Engine CLI.

01 / WORK

Tasks and event history

Create and update tasks, record events, and inspect current service status through documented routes.

02 / OPERATE

Backups and diagnostics

Run explicit backup, restore, schedule, and health-check operations through the local API.

03 / DISPATCH

Unified events and SSE

Persist canonical JSON envelopes, read the current dispatch state, and subscribe to the local event stream.

Reference overview

Endpoints at a glance

Start the API locally to view its generated OpenAPI reference at /docs.

GET /health

Check whether the local API process responds.

GET | POST /api/v1/tasks

Use PATCH on a task ID to edit it; completion and reopen actions change task status.

GET | POST /api/v1/events

Read and record events in the project history.

GET /api/v1/status | GET /api/v1/doctor

Inspect local engine status and run diagnostics.

POST /api/v1/backups | backup schedule

Create backups; manage schedules at /api/v1/backups/schedule.

GET /api/v1/export | POST /api/v1/restore

Export local records or restore from a validated backup.

POST /api/v1/unified/dispatch

Validate and persist a canonical cross-language event envelope.

GET /api/v1/unified/state | GET /api/v1/unified/stream

Read a state snapshot or subscribe to replayable server-sent events.

Security model

Local first. Explicit access.

This site is documentation only. It does not proxy requests, store API tokens, or expose the Aether Engine API to the public internet.

  • The API binds to loopback by default.
  • Remote server access requires an AETHER_API_TOKEN; loopback clients are trusted.
  • Never put a shared API token in Wix page code or browser JavaScript.
  • Public multi-user API hosting requires a separate deployment and security review.
